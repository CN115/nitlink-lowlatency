NitLink CN115 v0.1.1 — 简体中文支持

新增简体中文（zh-CN），覆盖视频、音频、快捷键、关于页面、提示说明、无信号页面、HUD 和错误提示。
设置 → 视频 → 面板 → 语言，可选择简体中文、繁體中文、English 或系统默认。
简体中文 Windows 自动选择简体中文；已有手动语言选择保持不变。切换立即生效并保存。
使用微软雅黑 UI 显示原生简体中文，保留英文缺失翻译回退。
音频缓冲、时钟漂移补偿、独占最小周期和失焦回退功能均保留。
关于页面、安装包和 EXE 版本统一为 0.1.1。

下载 NitLink-CN115-v0.1.1-win64.zip，完整解压后运行 NitLink.exe。
从 v0.1.0 升级时，先退出旧程序，再覆盖程序文件并保留原有 nitlink.json。
如果系统不是简体中文，可在上述语言菜单手动切换。

验证：Windows x64 Release 编译、CTest 回归测试、简体中文资源完整性与占位符检查、浏览器界面检查、发布包 SHA-256 校验。
Windows 构建测试不代替实际采集卡和声卡测试。WebView2 原生运行时测试未在 CI 中启用。
