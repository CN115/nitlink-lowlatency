NitLink CN115 v0.1.0 — 首个低延迟音频版本

本 fork 基于 nitlink-dev/nitlink d522bdc，集中改进采集卡音频播放延迟。

功能
- 可调 Capture FIFO / 共享播放队列；sinc 格式转换与自适应时钟漂移补偿。
- 可选 WASAPI 独占输出，自动申请设备报告的最小周期，并处理驱动缓冲对齐。
- 窗口失焦、最小化或隐藏后释放独占并切回共享；前台稳定 200 ms 后自动恢复。
- NitLink 自己的设置面板、子控件和所属对话框不会触发误回退。
- 关闭窗口时优先停止音频、释放声卡，不再等待其他后台模块清理完成。
- 独占初始化/运行失败回退共享，显示周期、格式、错误阶段和错误码。
- 用户设置保留；临时失焦不会关闭已保存的独占选项。

Windows 使用
下载 NitLink-CN115-v0.1.0-win64.zip，完整解压后运行 NitLink.exe。
需要 Windows 10 1809+ / Windows 11 和 Microsoft Edge WebView2 Runtime；VC++ 运行库随包提供。
F1 → Audio → Exclusive output (minimum period) 开启独占；先保持 FIFO 12 ms、漂移补偿开启。
独占仅在 NitLink 位于前台时生效；后台通过共享模式继续播放，切换时可能短暂断音。
在另一台程序中播放声音、Alt+Tab 切回 NitLink、最小化、打开设置以及退出，检查声卡释放/恢复。

验证与限制
Windows x64 Release 构建与自动化测试通过；包含独占缓冲协议、格式转换、漂移、
配置持久化、窗口归属、失焦释放和恢复延时回归测试。
用户在一台主板声卡上已反馈前版独占模式可到 3 ms；这不代表所有设备都支持，
也不代表端到端音频延迟只有 3 ms。本版新增的失焦/恢复行为仍需真实硬件测试。
